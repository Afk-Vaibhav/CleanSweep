# 🌱 Civic Cleanliness Platform

A community-driven web platform designed to make cities cleaner by connecting people who report dirty locations with volunteers who are willing to clean them for rewards.

---

## 🚀 Overview

The Civic Cleanliness Platform allows users to:

* 📸 Report polluted or dirty places in their city
* 📍 View nearby cleaning tasks
* 🧹 Claim and complete cleaning tasks
* 💰 Earn rewards (simulated via frontend)
* 🤝 Contribute to making the environment cleaner

This project is built as a **multi-page responsive website** using core web technologies and is designed as a real-world MVP concept.

---

## ✨ Features

### 🏠 Home Page

* Clean and modern landing UI
* Hero section with CTA buttons
* “How it Works” section
* Platform statistics (dummy data)
* Testimonials section

### 📤 Report Page

* Upload image of dirty location
* Add location and description
* Form validation with success feedback

### 📋 Tasks Page

* View all reported locations
* Task cards with:

  * Image
  * Location
  * Reward amount
* “Claim Task” functionality

### 📊 Dashboard Page

* User profile overview
* Stats (tasks completed, earnings)
* List of claimed tasks

### ℹ️ About Page

* Mission and vision
* Problem explanation
* How the platform works

## ⚙️ How It Works (Frontend Simulation)

* Tasks are generated using **dummy JSON data**
* “Claim Task” updates UI dynamically
* Form submissions show success messages
* No backend integration (currently)

## 🧪 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/civic-cleanliness-platform.git
   ```

2. Open the project folder:

   ```bash
   cd civic-cleanliness-platform
   ```

3. Run:

   * Open `index.html` in your browser
